# Pílulas (conteúdo didático)

Uma pílula por tópico da matriz, sempre com o mesmo roteiro:

1. Explicação curta (texto simples + ilustração, opção de áudio)
2. Exemplo resolvido passo a passo
3. "Agora você": 2–3 exercícios interativos com dica
4. Mini-checagem de 3 questões (acertou → tópico "aprendido")
5. Revisão agendada alguns dias depois

Formato sugerido de arquivo: `pilula-<topico>.json` ou `.md` com cabeçalho, ligado às questões pelo campo `pilula_id`.

Primeira pílula a criar: `pilula-sequencias-padroes` (usada pela questão de exemplo).
